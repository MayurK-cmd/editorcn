Templates are complete editors built from `@editorcn/editor`. Each one installs as a shadcn block, and the CLI adds the editor component for you. You own the code after install, so you can change anything.

<Callout title="Templates use Tailwind CSS">
  The editor and static renderer ship plain CSS and work in any React app. Templates are styled with Tailwind CSS v4 and built on shadcn/ui components (Button, Dropdown Menu, Popover, Avatar, Kbd), so your project needs Tailwind and shadcn/ui set up. Run `npx shadcn@latest init` first if it isn't.
</Callout>

All templates store content as Tiptap JSON (`editor.getJSON()`) and display it with the [Static Renderer](/docs/static-renderer), which renders React elements instead of HTML. Content renders on the server and stored content can't inject scripts. Use `generateHTML(json, extensions)` from `@tiptap/core` when you need HTML, for example in emails.

## Chat Composer

A chat interface built on the editor: a centered thread, a rounded input with a bubble menu for formatting, copy, edit and regenerate actions on each message, a stop button while a reply streams, and a jump-to-latest button.

Pass `onSend` to connect your model. It receives the user's message as Tiptap JSON. Return the reply as plain text, an async iterable of text chunks to stream it, or Tiptap JSON. Use the `signal` to cancel your request when the user presses stop. Throw to mark the message as failed with a retry.

```tsx
<ChatComposer
  onSend={async function* (content, { signal }) {
    const res = await fetch("/api/chat", {
      body: JSON.stringify(content),
      method: "POST",
      signal,
    });
    const reader = res.body!.pipeThrough(new TextDecoderStream()).getReader();
    for (;;) {
      const { done, value } = await reader.read();
      if (done) return;
      yield value;
    }
  }}
/>
```

Turn on `attachments` to let people add images with the `+` button, by pasting, or by dropping them on the input. Files are handed to `onSend` as `files`; uploading them is up to your backend. `accept` (default `image/*`) and `maxFiles` (default 4) limit what can be added. Pass `models` as `{ label, value, icon }` objects to show a model picker; the selected `value` arrives as `model`.

```tsx
<ChatComposer
  attachments
  models={[
    { icon: <ClaudeIcon />, label: "Claude Opus", value: "claude-opus" },
    { icon: <ClaudeIcon />, label: "Claude Sonnet", value: "claude-sonnet" },
  ]}
  onSend={(content, { files, model, signal }) => sendToYourApi({ content, files, model, signal })}
/>
```

## Comment Box

A comment thread with avatars, relative times, emoji reactions, and a composer built on the editor. People can copy any comment and delete their own. `onPost`, `onReact` and `onDelete` let you save each change to your backend.

```tsx
<CommentBox
  currentUser={{ avatar: user.image, id: user.id, name: user.name }}
  initialComments={comments}
  onPost={(content) => saveComment(content)}
  onReact={(id, emoji) => toggleReaction(id, emoji)}
  onDelete={(id) => deleteComment(id)}
/>
```
